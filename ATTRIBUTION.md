# Third-party assets

The playable `index.html` embeds the following third-party assets for offline use.
They remain under their original licenses and are **not** relicensed under the project MIT license.

| Asset | Author / source | License |
| --- | --- | --- |
| Three.js r128 (`three.min.js`, GLTFLoader, SkeletonUtils, RoundedBoxGeometry) | three.js contributors — https://threejs.org | MIT |
| `Soldier.glb` (Vanguard character with Idle/Walk/Run animations) | three.js examples `models/gltf/Soldier.glb`; character originating from Mixamo | Three.js examples / Mixamo terms |
| Flat Guns West weapon models (`Pistol_Full`, `Pistol_Compact`, `SMG_Compact`, `SMG_Full`, `Shotgun_Pump`, `Rifle_Assault`, `Rifle_Battle`, `Sniper_Rifle`) | petroulacl, FPS Asset Kit — https://github.com/petroulacl/fps-asset-kit | CC0 |
| Concrete / asphalt PBR textures | Poly Haven — https://polyhaven.com | CC0 |
| UI, HUD, maps, props, effects, audio synthesis | BLACKSITE ZERO project | MIT |

No assets from Delta Force / Team Jade / Tencent are included. The game is an original
extraction-shooter prototype inspired by the genre, not a 1:1 reproduction.

If you redistribute the single HTML file, keep this attribution with it.
